# SBWObs & SB_Ident

Docs:
- SBWObs tool: https://ssd.jpl.nasa.gov/tools/sbwobs.html
- SB_Ident API: https://ssd-api.jpl.nasa.gov/doc/sb_ident.html

SB_Ident typical inputs:
- Observer location or site id
- UTC time
- Field-of-view center RA/Dec, angular width/height, and rotation
- Optional magnitude constraints

Returns known small bodies inside the field of view with identifiers and brightness metadata.
